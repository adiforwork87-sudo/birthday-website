# 🎂 Birthday Surprise Website

An interactive birthday surprise website built with HTML, CSS and JavaScript.

## ✨ Features

- 🎁 Interactive surprise reveal
- ✍️ Animated typing effects
- 💖 Personalized birthday messages
- 📸 Memory/photo section
- 🎵 Background music
- ✨ Smooth animations and transitions
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
